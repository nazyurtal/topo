# topo

Create and sculpt topographic shapes in your browser.

[Try topo](https://nazyurtal.github.io/topo/)

- Explore 2D contours, 3D landscapes, and layered terrain.
- Adjust layers, spacing, base depth, camera, lines, colors, and canvas size.
- Sculpt terrain and export editable SVG or PNG.

Open `index.html` in your browser to get started.
